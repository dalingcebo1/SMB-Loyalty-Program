# Docs Pack Checklist

- [ ] Consolidate high-value docs into `docs/` (Deployment, Architecture, Testing)
- [ ] Mark ephemeral or AI-guidance docs as private (do not commit)
- [ ] Add doc references in `README.md` and `CONTRIBUTING.md` where relevant
- [ ] Keep short how-tos (e.g., `make` targets, running tests) in a single `docs/quick-start.md`
- [ ] Review all README-like files at each release and archive outdated ones under `docs/archived/`
- [ ] Ensure code-level docs (API docs, OpenAPI snapshots) remain under `Backend/tests/` or `docs/` as appropriate
- [ ] Run a documentation audit once per quarter
